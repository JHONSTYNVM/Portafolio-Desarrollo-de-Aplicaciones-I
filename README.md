## DESCRIPCIÓN

Este repositorio corresponde al portafolio académico del curso de **Desarrollo de Aplicaciones I**.

Aquí se organizarán de manera progresiva las actividades, ejercicios, prácticas y proyectos desarrollados durante el curso.

Los trabajos estarán distribuidos por semanas y cada actividad podrá incluir, según corresponda:

- Proyecto desarrollado.
- Código fuente.
- Archivos utilizados.
- Informe académico.
- Evidencias de ejecución.
- Archivo comprimido para descarga y revisión.
