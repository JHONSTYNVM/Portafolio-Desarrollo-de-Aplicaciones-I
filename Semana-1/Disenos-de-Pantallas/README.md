# DISEÑOS DE PANTALLAS

En esta sección se presentan los prototipos visuales desarrollados para las futuras interfaces del curso de **Desarrollo de Aplicaciones I**.

Los diseños fueron elaborados como referencia previa a su implementación mediante **Java Swing y JFrame**, manteniendo una estructura visual coherente con la identidad institucional de la UPLA.

## Diseños incluidos

- Calculadora de área y perímetro de un rectángulo.
- Calculadora de hipotenusa mediante el Teorema de Pitágoras.
- Pantalla de inicio de sesión UPLA.
- Pantalla de inicio de sesión Banco UPLA.

Estos prototipos servirán como base visual para el posterior desarrollo y programación de las aplicaciones de escritorio.
